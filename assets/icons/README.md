# Interface icon sources

The handoff ZIP icon uses **file-zip** from [Tabler Icons](https://tabler.io/icons?icon=file-zip),
retrieved on 20 October 2026 from
https://github.com/tabler/tabler-icons/blob/main/icons/outline/file-zip.svg.
Its original path geometry is embedded as `i-file-zip` in the homepage SVG sprite;
size, stroke and colour follow the existing destination-icon styles.
The MIT license is preserved in `tabler-LICENSE.txt`.
