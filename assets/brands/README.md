# Official destination brand marks

Unmodified SVGs downloaded on 20 October 2026:

- `claude.svg`: **Claude Spark – Clay**, from the [Anthropic newsroom press kit](https://www.anthropic.com/news), downloaded from https://anthropic.com/press-kit.
- `figma.svg`: **Figma Icon (Full-color)**, from [Figma brand resources](https://www.figma.com/using-the-figma-brand/), downloaded from https://static.figma.com/uploads/4fbf4d754dbbc027ba1530205f8747cd97d532e5.

The SVG source, aspect ratios and brand colours are unchanged. CSS crops only
the generous transparent margins around the Figma mark to match its optical size
to Claude; the coloured paths remain intact. These identify
handoff destinations; they are not Flow Capture logos or endorsement badges.
