01

Claude verbinden

Beginnen Sie mit dem Verzeichnis und aktivieren Sie dann Flow Capture in Ihrem Chat.

  1. Öffnen Sie auf Ihrem Computer Flow Capture im Claude-Connector-Verzeichnis. Sie können es auch über Customize → Connectors finden.
  2. Wählen Sie „Mit Claude verbinden“.
  3. Lassen Sie die Seite Flow Capture geöffnet und genehmigen Sie den Code auf Ihrem iPhone wie unten beschrieben.
  4. Kehren Sie zu Claude zurück und aktivieren Sie Flow Capture in dem Chat, in dem Sie es verwenden möchten.
02

Genehmigen Sie auf Ihrem iPhone

Ein einmaliger Code verknüpft Claude mit Ihrem Flow Capture-Konto.

  1. Verwenden Sie den Browsercode

    Ihre KI-App öffnet eine Flow Capture-Seite mit einem Code wie ABCD-EFGH. Lassen Sie diese Seite geöffnet.

  2. Genehmigen in Flow Capture

    Öffnen Sie Settings → Integrations → Codex & Claude → Add a Computer. Melden Sie sich an, wenn Sie dazu aufgefordert werden, geben Sie den Code ein, überprüfen Sie den Namen der anfordernden App und bestätigen Sie.

  3. Kehren Sie zu Ihrer KI-App zurück

    Der Browser stellt die Verbindung her. Aktivieren Sie in Claude Flow Capture für den Chat, in dem Sie ihn verwenden möchten. Eine direkte Verbindung ist derzeit für Claude verfügbar.

Codes sind nur für den einmaligen Gebrauch bestimmt und können in bis zu 10 Minuten ablaufen. Wenn ein Code abläuft, starten Sie Connect erneut in derselben AI-App. Sie benötigen niemals ein Supabase-Konto, einen API-Schlüssel oder eine Serverinstallation.

03

Senden Sie einen Flow zur Überprüfung

Sie wählen die Bildschirme aus. Die Verbindung allein teilt nichts.

  1. Senden Sie die entsprechenden Bildschirme

    Öffnen Sie einen Flow → Share → Export for Codex or Claude → Send to AI. Für eine kleinere Übergabe verwenden Sie Select Screens und exportieren Sie nur Ihre Auswahl.

  2. Starten Sie die Überprüfung

    Tippen Sie nach dem Senden auf Copy Request und fügen Sie es in Ihren verbundenen Claude-Chat ein. Fügen Sie hinzu, was Sie überprüfen oder ändern möchten. Die Anfrage identifiziert den genauen Export, auch wenn mehrere Versionen den gleichen Namen haben.

  3. Suchen Sie nach einem früheren Export

    Fragen Sie: „Zeigen Sie die von mir freigegebenen Flow Capture-Exporte und öffnen Sie den neuesten für [Projektname].“ Auf Ihrem iPhone können nur verfügbare freigegebene Kopien gefunden werden, keine nicht gesendeten Projekte.

Transkribieren Sie wichtige Sprachkommentare vor dem Senden. Das Originalvideo bleibt auf dem iPhone. Jeder Export ist eine Momentaufnahme: Senden Sie aktualisierte Bildschirme erneut, um Änderungen zu teilen. Bis zu 200 Bildschirme und 50 MB pro Cloud-Export. Shared-Kopien verfallen nach 7 Tagen.

Teilen Sie lieber eine Postleitzahl?
  1. Exportieren Sie die ausgewählten Bildschirme und Kommentare als AI-Review-ZIP.
  2. Share es mit einer KI-App, die Dateien akzeptiert. Wenn ZIPs nicht geöffnet werden können, extrahieren Sie zuerst das Paket.
  3. Hängen Sie START_HERE.txt und die relevanten Bildschirme an und beschreiben Sie dann, was Sie überprüfen möchten.
Lesen Sie den Leitfaden zur ZIP-Übergabe

Anforderungen & Verfügbarkeit

Kein Connector-Download oder lokaler Server. Sie benötigen Flow Capture auf dem iPhone und Zugriff auf Claude. Für die direkte Cloud-Bereitstellung ist Flow Capture Pro erforderlich. Der Plan und die Nutzungsbeschränkungen Ihrer KI-App gelten separat. Die iPhone-App kommt bald.

Fragen & Hilfe

Verbindung, Teilen und Zugriff.

Muss ich für einen Server bezahlen?

Nein. Flow Capture führt den Connector für Sie aus. Für das direkte Senden in die Cloud ist Flow Capture Pro erforderlich. Die eigenen Nutzungsbeschränkungen Ihres Claude-Kontos gelten separat.

Läuft meine Verbindung ab?

Verbindungen erneuern sich während der Nutzung automatisch. Stellen Sie nach 90 Tagen ohne Nutzung erneut eine Verbindung in Ihrer AI-App her und genehmigen Sie einen neuen Code auf dem iPhone. Shared-Exportkopien haben eine separate Lebensdauer von 7 Tagen.

Ich habe einen Flow gesendet, aber in meinem KI-Chat wurde nichts angezeigt

Send to AI stellt einen Export zur Verfügung; Es wird keine Nachricht gepostet. Tippen Sie nach dem Senden auf Copy Request, fügen Sie es in Ihren verbundenen KI-Chat ein und fordern Sie die Überprüfung an. Die Antwort erscheint in diesem Chat.

Flow Capture ist verbunden, aber Claude verwendet es nicht

Aktivieren Sie Flow Capture für den aktuellen Chat im Connector-Menü von Claude. Senden Sie dann Ihre Bildschirme aus der iPhone-App und fügen Sie Copy Request in diesen Chat ein. Durch die Verbindung allein wird weder ein Projekt geteilt noch eine Überprüfung gestartet.

Mein Projekt fehlt

Stellen Sie sicher, dass der Computer mit demselben Flow Capture-Konto verbunden ist, das zum Senden des Exports verwendet wurde. Senden Sie die erforderlichen Bildschirme erneut, wenn die Kopie abgelaufen ist oder entfernt wurde. Fügen Sie das neueste Copy Request ein, um den genauen Export auszuwählen.

Kann ich nur einen aktualisierten Bildschirm senden?

Ja. Verwenden Sie Send Screens oder Select Screens, lassen Sie die relevanten Bildschirme ausgewählt und senden Sie einen neuen Export. Fügen Sie den neuen Copy Request in denselben KI-Chat ein. Lesen Sie den Leitfaden zur Bildschirmüberprüfung.

Verwendet MCP Transkriptionsprotokolle?

Nein. Bei der Umwandlung von Sprache in Text werden Minuten verwendet. Für das Herstellen einer Verbindung, das Senden von Screenshots und das Lesen eines Exports werden keine Transkriptionsminuten verbraucht.

Kann die KI mein Flow Capture-Projekt bearbeiten?

Dieser Connector ist schreibgeschützt. Es kann die von Ihnen gesendeten Bildschirme und Kommentare überprüfen. Es ist nicht möglich, Ihr Telefon aufzuzeichnen, Ihre Bibliothek zu ändern oder Einkäufe zu tätigen. Ein Assistent kann Ihnen bei der Bearbeitung von Code in seinem eigenen Arbeitsbereich helfen, wenn Sie ihn darum bitten.

Wie entferne ich den Zugriff?

Öffnen Sie Settings → Integrations → Codex & Claude auf dem iPhone und trennen Sie dann den Computer aus seinem Menü. Mit Shared Access können Sie freigegebene Kopien entfernen. Bereits heruntergeladene Dateien können nicht zurückgerufen werden.
