Aufzeichnung und Kommentare

  • Nehmen Sie eine iPhone-App auf und überprüfen Sie deren Bildschirme
  • Fügen Sie Sprachkommentare hinzu und überprüfen Sie Transkripte
  • Screenshots und Kommentare an Claude senden

Schließen Sie Ihren Computer an

Folgen Sie dem MCP-Setup, um Claude aus der Ferne zu verbinden, auf Ihrem iPhone zu genehmigen und einen Flow zu senden. Die Einrichtungsseite enthält Hilfe für fehlende Tools, abgelaufene Codes, das Senden eines Bildschirms und das Starten einer Überprüfung. Es ist keine lokale Connector-Installation erforderlich. Öffnen Sie für Claude Flow Capture im Connector-Verzeichnis und wählen Sie „Mit Claude verbinden“ aus.

Käufe und Abonnements

Öffnen Sie Settings → Konto → Abonnement verwalten in Flow Capture, um Ihr Abonnement zu verwalten. Sie können es auch im Menü Settings → Ihr Name → Abonnements Ihres iPhones verwalten. Bei App Store Rechnungsproblemen oder Rückerstattungsanträgen nutzen Sie Apples Kaufsupport.

Löschen Sie ein Konto oder geben Sie Speicherplatz frei

Verwenden Sie Settings → Account → Delete Account, um Ihr Flow Capture-Cloud-Konto und die zugehörigen Cloud-Daten zu entfernen. Lokale Projekte bleiben auf Ihrem iPhone. Durch die Kontolöschung wird ein Apple-Abonnement nicht gekündigt.

Verwenden Sie Settings → Speicher, um Projektgrößen zu überprüfen und Videos oder ganze Projekte zu löschen. Wenn Sie nur das Video löschen, bleiben Screenshots und Kommentare erhalten, es können jedoch keine weiteren Frames aus diesem Video wiederhergestellt werden.

Erstellen Sie einen Problembericht

Öffnen Sie in Flow Capture Settings → Problem melden, um einen Bericht vorzubereiten. Geben Sie an, was Sie erwartet haben, was passiert ist und welche Schritte zur Reproduktion erforderlich sind. Senden Sie den Bericht an support@flowcap.me. Geben Sie keine Passwörter, Pairing-Codes oder privaten Aufzeichnungen an.
