So nimmst du eine iPhone-App für eine gezielte UX-Analyse auf

Erfassen Sie einen App-Benutzerfluss, wählen Sie nützliche Screenshots aus und verwandeln Sie eine iPhone-Bildschirmaufzeichnung in einen überprüfbaren Fluss mit Flow Capture.

Eine nützliche UX-Aufzeichnung folgt einer Aufgabe von Anfang bis Ende. Anstatt irrelevante Screenshots zu sammeln, erfassen Sie die Entscheidungen, Übergänge und Zustände, die erklären, was eine Person zu tun versucht. Flow Capture verwandelt diese Aufzeichnung in einen Ablauf, den Sie überprüfen und teilen können.

Beginnen Sie mit einer Frage

Wählen Sie einen kleinen Benutzerfluss: eine Unterkunft finden, sich anmelden oder eine Einstellung ändern. Schreiben Sie vor der Aufnahme auf, was Sie verstehen möchten. „Wo wird die Terminauswahl verwirrend?“ ist einfacher zu überprüfen als „Sehen Sie sich diese ganze App an.“

Öffnen Sie die Ziel-App auf dem Startbildschirm. Aktivieren Sie „Bitte nicht stören“ und suchen Sie nach privaten Informationen, die nicht in Ihrer Aufnahme erscheinen sollen. Ein sauberer Ausgangspunkt gibt dem resultierenden Fluss einen klaren Anfang.

Zeichnen Sie den Benutzerfluss auf

  1. Starten Sie eine Aufnahme in Flow Capture. Wählen Sie im iOS-Broadcast-Panel Flow Capture aus und tippen Sie auf Start Broadcast.
  2. Wenn Sie erzählen möchten, aktivieren Sie Microphone, bevor Sie beginnen. Sprechen Sie, während der entsprechende Bildschirm sichtbar ist.
  3. Bewegen Sie sich ganz natürlich durch die App. Machen Sie bei jedem bedeutungsvollen Zustand eine kurze Pause, damit Sie ihn von einem Übergang unterscheiden können.
  4. Kehren Sie zu Flow Capture zurück und wählen Sie Finish Recording. Lassen Sie die App geöffnet, während die Aufnahme gespeichert und angehängt wird.

Geben Sie sowohl das Ergebnis als auch die Aktion an. Zeigen Sie beispielsweise nach dem Absenden einer Suche die Suchergebnisse an, nicht nur die Schaltfläche, auf die Sie getippt haben. Wenn ein Fehler Teil des Erlebnisses ist, belassen Sie den Fehler und den Wiederherstellungsschritt im selben Benutzerfluss.

Sehen Sie sich die Bildschirme an, bevor Sie sie teilen

Die Bildschirmauswahl läuft auf Ihrem iPhone. Überprüfen Sie das Ergebnis, um sicherzustellen, dass die Schlüsselzustände vorhanden sind und wiederholte Frames nicht von der Aufgabe ablenken. Wenn ein Status übersehen wurde, verwenden Sie Frame Editor, um ihn aus der Originalaufzeichnung wiederherzustellen, sofern verfügbar.

Geben Sie Bildschirmen sinnvolle Namen und organisieren Sie verwandte Schritte in Abläufen. Die Karte hilft zu erklären, wie diese Schritte zusammenhängen. Die Screenshots zeigen, wie die einzelnen Schritte aussahen. Beides ersetzt keinen kurzen Kommentar, der das Problem erläutert, das jemand bemerken soll.

Konzentrieren Sie sich auf die erste Aufnahme

Eine kurze Aufzeichnung einer kompletten Aufgabe ist oft einfacher umzusetzen als eine lange Tour. Wenn Sie einen anderen Zweig untersuchen müssen, erfassen Sie diesen Zweig separat und behalten Sie seinen Kontext mit dem Projekt bei. Überprüfen Sie Ihre persönlichen Daten, bevor Sie etwas exportieren.

Behalten Sie beim Überprüfen die Quelle bei.

Durch das Löschen des Originalvideos wird Speicherplatz frei, Sie können jedoch später keine weiteren Frames aus diesem Video wiederherstellen. Wählen Sie zunächst die benötigten Bildschirme aus.

Was als nächstes zu tun ist

Fügen Sie Sprach- oder Textkommentare hinzu, um die wichtigen Momente zu erklären. Wenn der Flow bereit ist, senden Sie die ausgewählten Bildschirme an Claude oder bereiten Sie eine Figma-Übergabe vor.
