Zu den Anleitungen
Was ist Flow Capture?

Flow Capture wandelt den Benutzerfluss einer iPhone-App in geordnete Bildschirme und mit dem Bildschirm verknüpfte Kommentare um, sodass Sie den Fluss überprüfen und eine nützliche Übergabe vorbereiten können.

Was kann ich aufnehmen oder importieren?

Zeichnen Sie den Benutzerfluss einer iPhone-App auf oder importieren Sie eine vorhandene Aufzeichnung oder eine Reihe von Screenshots. iOS oder die Quell-App verhindern möglicherweise die Erfassung geschützter Inhalte.

Kann ich Sprachkommentare hinzufügen?

Ja. Sie können während einer Aufnahme kommentieren und Textkommentare zu gespeicherten Bildschirmen hinzufügen. Neue Sprachnotizen und Cloud-Transkription hängen von Ihrem Plan und dem verbleibenden Kontingent ab. Überprüfen Sie die Platzierung von Kommentaren und transkribieren Sie wichtige Audioinhalte vor einer KI-Übergabe. Für die Bildschirmaufnahme selbst werden keine Transkriptionsminuten benötigt. Mehr zu Sprachkommentaren.

Verlassen meine Aufnahmen das Gerät?

Originalaufnahmen und gespeicherte Projekte bleiben auf Ihrem iPhone. Die Bildschirmauswahl erfolgt lokal. Wenn Sie Sprachtranskription, Kommentarpolierung, direkte Figma-Zustellung oder MCP-Freigabe anfordern, senden diese optionalen Dienste die relevanten Audio-, Text- oder Exportdaten für diese Aktion. Offline-Exporte bleiben lokal, bis Sie sie teilen.

Kann ich meine Screens mit Claude nutzen?

Ja. Verbinden Sie Flow Capture mit Claude, um Materialien direkt zu senden. Derzeit wird nur Claude direkt unterstützt. Alternativ können Sie eine ZIP-Datei für die KI-Analyse teilen, ohne eine KI-App zu verbinden. Kopieren Sie nach Send to AI die Anfrage über Copy Request und fügen Sie sie in den Claude-Chat ein. Jeder Versand erstellt eine eigene Kopie und aktualisiert frühere Exporte nicht. So geben Sie Materialien weiter.

Was kann ich an Figma übergeben?

Das Plugin importiert Screenshots als geordnete Bildebenen, gruppiert nach Ablauf. Es erstellt daraus keine editierbaren UI-Komponenten. Die öffentliche Veröffentlichung wird vorbereitet; ein Download über Figma Community ist noch nicht verfügbar.

Kann ich Flow Capture schon herunterladen?

Die iPhone-App und das Figma-Plugin werden für die öffentliche Veröffentlichung vorbereitet. Flow Capture erscheint bald im App Store.
