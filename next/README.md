# Alternate landing at /next/

Standalone English comparison page. The production homepage and its eight
language versions stay unchanged. `noindex, follow` keeps this experiment out
of search results; canonical and OG URL identify /next/.

The page reuses approved local product artwork, the lake hero and landing.js
for exclusive viewport playback, restart controls, header and parallax. All new
styles are in next.css and scoped to .next-page. No build step is needed.

Differences: heavier typography, centered hero, compact three-step intro,
full-width capture panel, detail compositions for comments/map, a version
spread, a concrete Claude prompt, a product note, and shorter FAQ. The product
note makes no unsupported claims about the maker. Existing release and privacy
qualifications are preserved.

Reviewed at 320, 390, 768 and 1440 px. Links and assets resolve from the root.
Use the Original links in the header/footer to compare with the homepage.
