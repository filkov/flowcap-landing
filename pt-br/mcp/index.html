01

Conectar Claude

Comece com o diretório e ative Flow Capture em seu chat.

  1. No seu computador, abra Flow Capture no diretório do conector Claude. Você também pode encontrá-lo em Customize → Connectors.
  2. Escolha Conectar a Claude.
  3. Mantenha a página Flow Capture aberta e aprove seu código no seu iPhone conforme descrito abaixo.
  4. Volte para Claude e habilite Flow Capture no chat onde deseja utilizá-lo.
02

Aprovar no seu iPhone

Um código único vincula Claude à sua conta Flow Capture.

  1. Use o código do navegador

    Seu aplicativo AI abre uma página Flow Capture mostrando um código como ABCD-EFGH. Mantenha essa página aberta.

  2. Aprovar em Flow Capture

    Abra Settings → Integrations → Codex & Claude → Add a Computer. Faça login se solicitado, insira o código, verifique o nome do aplicativo solicitante e confirme.

  3. Retorne ao seu aplicativo de IA

    O navegador conclui a conexão. Em Claude, habilite Flow Capture para o chat onde deseja usá-lo. A conexão direta está atualmente disponível para Claude.

Os códigos são descartáveis ​​e podem expirar em até 10 minutos. Se um código expirar, inicie o Connect novamente no mesmo aplicativo de IA. Você nunca precisa de uma conta Supabase, chave de API ou instalação de servidor.

03

Envie um fluxo para revisão

Você escolhe as telas. Conectar-se sozinho não compartilha nada.

  1. Envie as telas relevantes

    Abra um fluxo → Share → Export for Codex or Claude → Send to AI. Para uma transferência menor, use Select Screens e exporte apenas sua seleção.

  2. Comece a revisão

    Após o envio, toque em Copy Request e cole-o no chat Claude conectado. Adicione o que deseja revisar ou alterar. A solicitação identifica a exportação exata, mesmo quando várias versões possuem o mesmo nome.

  3. Encontre uma exportação anterior

    Pergunte: “Mostre as exportações Flow Capture que compartilhei e abra a mais recente para [nome do projeto].” Somente cópias compartilhadas disponíveis podem ser encontradas, e não projetos não enviados no seu iPhone.

Transcreva comentários de voz importantes antes de enviar. O vídeo original permanece no iPhone. Cada exportação é um instantâneo: envie novamente telas atualizadas para compartilhar as alterações. Até 200 telas e 50 MB por exportação para nuvem. As cópias Shared expiram após 7 dias.

Prefere compartilhar um ZIP?
  1. Exporte as telas e comentários selecionados como um ZIP de revisão de IA.
  2. Share com um aplicativo AI que aceita arquivos. Se não conseguir abrir ZIPs, extraia o pacote primeiro.
  3. Anexe START_HERE.txt e as telas relevantes e descreva o que deseja analisar.

Nenhum download de conector ou servidor local. Você precisa do Flow Capture no iPhone e acesso ao Claude. A entrega direta na nuvem requer Flow Capture Pro; o plano e os limites de uso do seu aplicativo de IA se aplicam separadamente. O aplicativo para iPhone estará disponível em breve.

Perguntas e ajuda

Conexão, compartilhamento e acesso.

Preciso pagar por um servidor?

Não. Flow Capture executa o conector para você. O envio direto para a nuvem requer Flow Capture Pro. Os limites de uso da sua conta Claude se aplicam separadamente.

Minha conexão irá expirar?

As conexões são renovadas automaticamente enquanto são usadas. Após 90 dias sem uso, conecte-se novamente em seu aplicativo de IA e aprove um novo código no iPhone. As cópias de exportação Shared têm uma vida útil separada de 7 dias.

Enviei um fluxo, mas nada apareceu no meu chat de IA

Send to AI disponibiliza uma exportação; não publica uma mensagem. Toque em Copy Request após enviar, cole-o em seu chat de IA conectado e peça a revisão. A resposta aparece nesse chat.

Flow Capture está conectado, mas Claude não o utiliza

Habilite Flow Capture para o bate-papo atual no menu do conector Claude. Em seguida, envie suas telas do aplicativo para iPhone e cole Copy Request nesse chat. Conectar-se sozinho não compartilha um projeto nem inicia uma revisão.

Meu projeto está faltando

Certifique-se de que o computador esteja conectado à mesma conta Flow Capture usada para enviar a exportação. Envie as telas necessárias novamente se a cópia expirou ou foi removida. Cole o Copy Request mais recente para selecionar a exportação exata.

Posso enviar apenas uma tela atualizada?

Sim. Utilize Send Screens ou Select Screens, mantenha as telas relevantes selecionadas e envie uma nova exportação. Cole seu novo Copy Request no mesmo chat de IA. Leia o guia de revisão de tela.

O MCP usa minutos de transcrição?

Não. Minutos são usados ​​ao converter fala em texto. Conectar, enviar capturas de tela e ler uma exportação não utiliza minutos de transcrição.

A IA pode editar meu projeto Flow Capture?

Este conector é somente leitura. Ele pode inspecionar as telas e os comentários que você envia. Ele não pode gravar seu telefone, alterar sua biblioteca ou fazer compras. Um assistente pode ajudar a editar o código em seu próprio espaço de trabalho quando você solicitar.

Como faço para remover o acesso?

Abra Settings → Integrations → Codex & Claude no iPhone e desconecte o computador do menu. Shared Access permite remover cópias compartilhadas. Os arquivos já baixados não podem ser recuperados.
