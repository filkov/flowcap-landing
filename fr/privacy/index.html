Flow Capture est une priorité locale. Les projets, captures d'écran, enregistrements d'écran et commentaires vocaux originaux restent sur l'iPhone de l'utilisateur, à moins que celui-ci ne les exporte ou ne les envoie délibérément.

Données utilisées pour les fonctionnalités cloud facultatives

  • Données du compte : le nom, l'adresse e-mail, un identifiant de compte privé, le droit d'achat et les métadonnées d'intégration connectée sont stockés pour fournir l'authentification, les achats, les allocations de transcription et les intégrations.
  • Traitement vocal : lorsqu'un utilisateur demande une transcription ou un polissage de commentaire, l'audio sélectionné ou le texte du commentaire ainsi que les titres d'écran liés et le texte d'interface reconnu sont envoyés de manière sécurisée aux fournisseurs de traitement de Flow Capture. L’audio cloud temporaire est supprimé une fois la demande terminée. L'audio original et le texte résultant restent dans le projet local.
  • Transfert Figma : un package de flux est téléchargé uniquement lorsque l'utilisateur choisit le transfert direct Figma. Pour associer le plugin avec le bon compte Flow Capture, le plugin envoie l'ID utilisateur Figma connecté et le nom d'affichage à Flow Capture. Un jeton de session de plug-in opaque est stocké dans le stockage client Figma. Les forfaits en attente sont disponibles jusqu'à sept jours. Les exportations ZIP hors ligne ne sont pas téléchargées par Flow Capture.
  • Transfert d'IA via MCP : un package n'est téléchargé qu'après que l'utilisateur a confirmé Send to AI. Il peut inclure des captures d'écran commandées, des commentaires, une invite et l'audio original disponible. Seuls les ordinateurs connectés par un code de couplage approuvé peuvent récupérer les exportations explicitement partagées du compte. Les copies expirent après sept jours et peuvent être supprimées plus tôt dans Settings → Codex & Claude → Shared Access. Les connexions à distance utilisent OAuth avec une approbation unique sur iPhone. Le service AI détient des informations d’identification d’accès et d’actualisation distinctes et révocables ; Flow Capture stocke les hachages d'informations d'identification et les informations d'identification chiffrées du fournisseur sur son serveur. Votre session iPhone n'est pas partagée avec le service AI. Les connexions se renouvellent en cours d'utilisation et expirent après 90 jours d'inactivité. La déconnexion empêche d'autres lectures, mais n'efface pas les fichiers déjà téléchargés par un service d'IA. Une fois que l'utilisateur demande à Claude ou Codex de lire une exportation, les conditions de traitement des données de ce client s'appliquent. Flow Capture ne démarre pas automatiquement les conversations AI.
  • Achats : Apple fournit des informations sur les transactions signées afin que Flow Capture puisse débloquer les fonctionnalités achetées et les minutes de transcription.

Les demandes de connecteur distant sont acheminées via Cloudflare. L'authentification, les enregistrements de connexion et le stockage d'exportation explicitement partagé sont hébergés sur Supabase. Ces fournisseurs traitent la connexion et demandent les données nécessaires à la réalisation de l'intégration ; le contenu partagé n’est pas accessible au public.

Flow Capture ne vend pas de données personnelles, ne les utilise pas à des fins publicitaires et ne suit pas les utilisateurs sur les applications et les sites Web. Les prestataires de services servent uniquement à fournir les fonctionnalités demandées par l'utilisateur et sont tenus de protéger les données qu'ils traitent.

Analyses de produits et réponses d'intégration facultatives

Le partage est désactivé jusqu'à votre inscription. Si vous choisissez Share Answers & Usage, Flow Capture envoie les options d'enquête sélectionnées, la version de l'application et les événements de base tels que les sessions d'application, la création de projet, l'ouverture de Flow Map et la préparation des exportations vers notre backend Supabase. Un identifiant d'installation aléatoire regroupe ces enregistrements ; il est distinct de votre compte cloud et ne constitue pas un identifiant publicitaire. Nous n'envoyons pas de noms, d'e-mails, de titres de projets, de captures d'écran, d'enregistrements, de textes de commentaires, de requêtes de recherche saisies ou d'autres contenus d'applications à des fins d'analyse. Les fournisseurs d'hébergement peuvent traiter les informations de connexion standard pour exploiter et protéger le service.

Vous pouvez désactiver le partage dans Settings → Privacy & Data. Cela efface les événements en file d’attente et demande la suppression des analyses envoyées par cette installation. En mode hors ligne, la suppression est retentée lorsque l'application est rouverte en ligne. Les enregistrements analytiques et les réponses aux enquêtes expirent après 90 jours. La réinstallation de l'application crée une nouvelle installation et nous ne pouvons pas identifier l'installation précédente à partir de votre courrier électronique ; ses enregistrements expirent automatiquement. La désactivation des analyses n'affecte pas les fonctionnalités ou les abonnements de l'application. Nous utilisons ces enregistrements pour améliorer Flow Capture, et non à des fins de publicité, de suivi inter-applications ou de formation à l'IA.

Conservation et suppression

L'audio de transcription temporaire est supprimé du stockage cloud après le traitement. Les packages de transfert direct Figma cessent d'être disponibles après sept jours et sont supprimés par le nettoyage de rétention de Flow Capture. La révocation de l'intégration Figma invalide immédiatement ses sessions de plugin ; les métadonnées de connexion inactives, y compris l'ID utilisateur et le nom d'affichage Figma, demeurent tant que le compte cloud Flow Capture existe.

Les utilisateurs peuvent supprimer définitivement leur compte cloud Flow Capture et les données cloud associées dans Settings › Account › Delete Account. Les projets et enregistrements locaux ne sont pas supprimés par la suppression du compte. La suppression d'un compte Flow Capture n'annule pas un abonnement Apple ; les abonnements peuvent être gérés dans les paramètres du compte App Store.

Après la suppression du compte, Flow Capture peut conserver les identifiants de transaction Apple minimum signés sans lien de profil actif si nécessaire pour empêcher le même achat d'être crédité plus d'une fois, résoudre les remboursements et respecter les obligations de transaction ou de prévention de la fraude.

Autorisations

L'accès à Microphone est demandé uniquement lorsque l'utilisateur active Voice Commentary ou enregistre un commentaire vocal. L'application continue de prendre en charge la capture et l'organisation locales sans compte cloud. Le plugin Figma demande l'autorisation currentuser uniquement pour le couplage de transfert direct facultatif ; les importations hors ligne n'utilisent pas le backend de Flow Capture.

Ce site Web

Ce site Web est hébergé sur GitHub Pages et utilise des polices fournies par Google Fonts. Ces fournisseurs reçoivent des informations de connexion standard, telles que votre adresse IP et les détails de la demande du navigateur, pour fournir le site Web et les polices. Nous n'utilisons pas de trackers publicitaires ou de scripts d'analyse sur ce site Web.

Demandes de confidentialité

La suppression du compte est disponible dans l'application en utilisant le chemin ci-dessus. Pour les demandes de confidentialité, contactez support@flowcap.me. Consultez l'Assistance pour obtenir de l'aide actuelle et des conseils concernant votre compte.
