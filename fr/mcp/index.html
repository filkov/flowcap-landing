01

Connecter Claude

Commencez par le répertoire, puis activez Flow Capture dans votre chat.

  1. Sur votre ordinateur, ouvrez Flow Capture dans le répertoire du connecteur Claude. Vous pouvez également le trouver via Customize → Connectors.
  2. Choisissez Se connecter à Claude.
  3. Gardez la page Flow Capture ouverte et approuvez son code sur votre iPhone comme décrit ci-dessous.
  4. Revenez à Claude et activez Flow Capture dans le chat où vous souhaitez l'utiliser.
02

Approuvez sur votre iPhone

Un code à usage unique relie Claude à votre compte Flow Capture.

  1. Utilisez le code du navigateur

    Votre application IA ouvre une page Flow Capture affichant un code tel que ABCD-EFGH. Gardez cette page ouverte.

  2. Approuver dans Flow Capture

    Ouvrez Settings → Integrations → Codex & Claude → Add a Computer. Connectez-vous si vous y êtes invité, entrez le code, vérifiez le nom de l’application demandeuse et confirmez.

  3. Revenez à votre application IA

    Le navigateur termine la connexion. Dans Claude, activez Flow Capture pour le chat dans lequel vous souhaitez l'utiliser. La connexion directe est actuellement disponible pour Claude.

Les codes sont à usage unique et peuvent expirer au bout de 10 minutes maximum. Si un code expire, redémarrez Connect dans la même application AI. Vous n'avez jamais besoin d'un compte Supabase, d'une clé API ou d'une installation de serveur.

03

Envoyer un flux pour examen

Vous choisissez les écrans. La connexion seule ne partage rien.

  1. Envoyer les écrans concernés

    Ouvrir un flux → Share → Export for Codex or Claude → Send to AI. Pour un transfert plus petit, utilisez Select Screens et exportez uniquement votre sélection.

  2. Commencer la révision

    Après l'envoi, appuyez sur Copy Request et collez-le dans votre chat Claude connecté. Ajoutez ce que vous souhaitez revoir ou modifier. La requête identifie l'export exact, même lorsque plusieurs versions portent le même nom.

  3. Rechercher une exportation précédente

    Demandez : "Affichez les exportations Flow Capture que j'ai partagées et ouvrez la dernière pour [nom du projet]". Seules les copies partagées disponibles peuvent être trouvées, pas les projets non envoyés sur votre iPhone.

Transcrivez les commentaires vocaux importants avant de les envoyer. La vidéo originale reste sur iPhone. Chaque exportation est un instantané : envoyez à nouveau des écrans mis à jour pour partager les modifications. Jusqu'à 200 écrans et 50 Mo par exportation cloud. Les copies Shared expirent après 7 jours.

Vous préférez partager un ZIP ?
  1. Exportez les écrans et les commentaires sélectionnés sous forme de ZIP de révision AI.
  2. Share avec une application AI qui accepte les fichiers. S'il ne peut pas ouvrir les fichiers ZIP, extrayez d'abord le package.
  3. Joignez le fichier START_HERE.txt et les écrans correspondants, puis décrivez ce que vous souhaitez examiner.
Lire le guide de transfert ZIP

Questions et aide

Connexion, partage et accès.

Dois-je payer pour un serveur ?

Non. Flow Capture gère le connecteur pour vous. L'envoi direct vers le cloud nécessite Flow Capture Pro. Les limites d'utilisation de votre compte Claude s'appliquent séparément.

Ma connexion va-t-elle expirer ?

Les connexions se renouvellent automatiquement lors de leur utilisation. Après 90 jours sans utilisation, connectez-vous à nouveau dans votre application AI et approuvez un nouveau code sur iPhone. Les copies d'exportation Shared ont une durée de vie distincte de 7 jours.

J'ai envoyé un flux, mais rien n'est apparu dans mon chat IA

Send to AI rend disponible un export ; il ne publie pas de message. Appuyez sur Copy Request après l'envoi, collez-le dans votre chat AI connecté et demandez la révision. La réponse apparaît dans ce chat.

Flow Capture est connecté, mais Claude ne l'utilise pas

Activez Flow Capture pour la discussion en cours dans le menu du connecteur de Claude. Envoyez ensuite vos écrans depuis l'application iPhone et collez Copy Request dans cette discussion. La connexion seule ne permet pas de partager un projet ni de lancer une révision.

Mon projet est manquant

Assurez-vous que l'ordinateur est connecté au même compte Flow Capture utilisé pour envoyer l'exportation. Renvoyez à nouveau les écrans requis si la copie a expiré ou a été supprimée. Collez le dernier Copy Request pour sélectionner l'exportation exacte.

Puis-je envoyer un seul écran mis à jour ?

Oui. Utilisez Send Screens ou Select Screens, conservez les écrans concernés sélectionnés et envoyez une nouvelle exportation. Collez son nouveau Copy Request dans le même chat AI. Lisez le guide de révision des écrans.

MCP utilise-t-il des minutes de transcription ?

Non. Les minutes sont utilisées lors de la conversion de la parole en texte. La connexion, l'envoi de captures d'écran et la lecture d'un export n'utilisent pas de minutes de transcription.

L'IA peut-elle modifier mon projet Flow Capture ?

Ce connecteur est en lecture seule. Il peut inspecter les écrans et les commentaires que vous envoyez. Il ne peut pas enregistrer votre téléphone, modifier votre bibliothèque ou effectuer des achats. Un assistant peut vous aider à modifier le code dans son propre espace de travail lorsque vous le lui demandez.

Comment puis-je supprimer l'accès ?

Ouvrez Settings → Integrations → Codex & Claude sur iPhone, puis déconnectez l'ordinateur de son menu. Shared Access vous permet de supprimer les copies partagées. Les fichiers déjà téléchargés ne peuvent pas être rappelés.
