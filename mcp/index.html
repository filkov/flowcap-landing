01 · INSTALL

Add Flow Capture to your AI app

This version uses a local connector for macOS. It is not yet listed in the Claude or Codex directories.

Before you start

Install Node.js LTS (20.9 or newer), then choose your AI app:

Claude Desktop

Install Claude for Mac in Applications. The setup script adds Flow Capture to its MCP configuration.

Codex

Install Codex CLI as well as your desktop app. The script uses the CLI to register the server in their shared configuration.

Download the connector

Download and unzip the package. No model API key is needed.

Download for Mac · ZIP

Version 0.3.1 · Source package · SHA-256 checksum

Run setup

Open Terminal. Type cd (including the space), drag the unzipped Flow-Capture-MCP folder into Terminal, and press Return. Then paste these two lines:

npm ci --ignore-scripts
node install.mjs --cloud https://omhelpzpkowcncvqfnuw.supabase.co

Setup downloads dependencies, checks the connector, and configures installed Claude Desktop and Codex CLI. Existing configuration is backed up. It does not upload your projects.

Restart and check

Quit and reopen your AI app, then start a new chat. In Claude, check Settings → Developer for flow-capture. For Codex, run codex mcp list in Terminal and look for flow-capture.

If your app is not listed in the setup output, install the prerequisite above and run setup again.

02 · CONNECT

Pair your iPhone

  1. On your Mac

    Paste this request into a new Claude or Codex chat:

    Connect to my Flow Capture account using MCP. Call connect_account and show me the pairing code. After I approve it on my iPhone, call check_connection.
  2. On your iPhone

    Open Flow Capture → Settings → Codex & Claude → Add a Computer. Sign in if asked. Enter the 8-character code and confirm the computer's name.

  3. Back in your chat

    Tell the assistant you approved the connection. It checks the connection and is ready to receive your exports. A code expires after 10 minutes; request another if needed.

03 · SEND

Choose what your AI sees

  1. Send a flow

    Open a flow on your iPhone and choose Share → Codex & Claude → Send to AI. Direct delivery requires Flow Capture Pro.

  2. Start the review

    Tap Copy Request and paste it into your AI chat. That request identifies the exact export you just sent. Sending alone does not start a conversation.

The package includes selected screenshots, comments and available comment audio. The original screen recording is not uploaded. Up to 200 screens and 50 MB per shared export; shared copies expire after 7 days.

Need a hand?

My AI cannot find Flow Capture

Check that setup completed without errors and printed your app's name. Restart the app and open a new chat. For Codex, confirm the CLI is installed and codex mcp list shows flow-capture. For Claude, check Settings → Developer and its server logs. This connector uses the desktop app, not Claude in a web browser.

Node or npm is not found

Install Node.js LTS using the link above, close Terminal and open it again. Run node --version and npm --version, then repeat setup from the unzipped folder.

The code expired or my computer is disconnected

Ask your AI for a new connection code. Return to Add a Computer, enter the code and approve the correct computer. Claude and Codex connect separately.

Can I use this without cloud delivery?

Yes. Save your AI ZIP from Flow Capture and transfer it to your Mac. The package README describes the optional offline inbox. You can also attach the ZIP directly if your AI client supports it.

How do I remove access?

On your iPhone, open Settings → Codex & Claude. Use the computer's menu to disconnect it. Shared Access lets you remove cloud copies sooner. Previously downloaded files cannot be retracted.
