02 · CONNECT

Pair
your iPhone.

Get a code in your AI chat, then approve the computer in Flow Capture.

  1. On your Mac

    Paste this request into a new Claude or Codex chat:

    Connect my Flow Capture account. Check the existing connection first. If disconnected, show a pairing code and wait for me to approve it on my iPhone before checking again.
  2. On your iPhone

    Open Flow Capture → Settings → Integrations → Codex & Claude → Add a Computer. Sign in if asked. Enter the 8-character code and confirm the computer's name.

  3. Back in your chat

    Tell the assistant you approved the connection. It checks the connection and is ready to receive your exports. A code expires after 10 minutes; request another if needed.

03 · SEND

Choose what
your AI sees.

Share the flow you want to work on, then start the review in your AI chat.

  1. Send a flow

    Open a flow on your iPhone and choose Share → Codex & Claude → Send to AI. Direct delivery requires Flow Capture Pro.

  2. Start the review

    Tap Copy Request and paste it into your AI chat. That request identifies the exact export you just sent. Sending alone does not start a conversation.

The package includes selected screenshots, comments and available comment audio. The original screen recording is not uploaded. Up to 200 screens and 50 MB per shared export; shared copies expire after 7 days.

TROUBLESHOOTING

Need
a hand?

Start with these checks if setup or pairing gets stuck.

My AI cannot find Flow Capture

Start a new chat and check that Flow Capture is enabled in its tools. In Claude, look in Settings → Extensions; in Codex, look in MCP settings. If needed, quit and reopen your AI app after its other tasks finish. This version works in the desktop app, not Claude in a web browser.

I previously used the Terminal installer for Claude

Install the extension above, then remove the old flow-capture entry in Settings → Developer. Keep Flow Capture, marked as managed by an extension. Your existing iPhone connection is reused.

Advanced source setup

The source package includes manual and offline instructions. It requires Node.js and npm. Quit Claude completely before running source setup for Claude; otherwise its settings may overwrite the installation when it closes.

The code expired or my computer is disconnected

Ask your AI for a new connection code. Return to Add a Computer, enter the code and approve the correct computer. Claude and Codex connect separately.

Can I use this without cloud delivery?

Yes. Save your AI ZIP from Flow Capture and transfer it to your Mac. The package README describes the optional offline inbox. You can also attach the ZIP directly if your AI client supports it.

How do I remove access?

On your iPhone, open Settings → Integrations → Codex & Claude. Use the computer's menu to disconnect it. Shared Access lets you remove cloud copies sooner. Previously downloaded files cannot be retracted.
