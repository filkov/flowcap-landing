02 · APPROVE

Confirm
on your iPhone.

A one-time code links the AI app to the Flow Capture account on your iPhone.

  1. Use the browser code

    Your AI app opens a Flow Capture page showing a code like ABCD-EFGH. Keep that page open.

  2. Approve in Flow Capture

    Open Settings → Integrations → Codex & Claude → Add a Computer. Sign in if asked, enter the code, check the requesting app’s name, and confirm.

  3. Return to your AI app

    The browser completes the connection. In Claude, enable Flow Capture for the chat where you want to use it. Claude and Codex connect separately.

Codes are single-use and can expire in up to 10 minutes. If a code expires, start Connect again in the same AI app. You never need a Supabase account, API key, or server installation.

03 · SEND & REVIEW

Choose what
your AI sees.

Connecting does not share your library. You choose each export.

  1. Send the relevant screens

    Open a flow → Share → Export for Codex or Claude → Send to AI. For a smaller handoff, use Select Screens and export only your selection.

  2. Start the review

    After sending, tap Copy Request and paste it into your connected Claude or Codex chat. Add what you want reviewed or changed. The request identifies the exact export, even when several versions have the same name.

  3. Find a previous export

    Ask: “Show the Flow Capture exports I shared and open the latest one for [project name].” Only available shared copies can be found, not unsent projects on your iPhone.

Transcribe important voice comments before sending. The original video stays on iPhone. Each export is a snapshot: send updated screens again to share changes. Up to 200 screens and 50 MB per cloud export. Shared copies expire after 7 days.

GOOD TO KNOW

Simple setup.
Clear boundaries.

Do I need to pay for a server?

No. Flow Capture runs the connector for you. Direct cloud sending requires Flow Capture Pro. Your Claude or Codex account’s own usage limits apply separately.

Will my connection expire?

Connections renew automatically while used. After 90 days without use, connect again in your AI app and approve a new code on iPhone. Shared export copies have a separate 7-day lifetime.

I sent a flow, but nothing appeared in my AI chat

Send to AI makes an export available; it does not post a message. Tap Copy Request after sending, paste it into your connected AI chat, and ask for the review. The answer appears in that chat.

My project is missing

Make sure the computer is connected to the same Flow Capture account used to send the export. Send the required screens again if the copy expired or was removed. Paste the latest Copy Request to select the exact export.

Can I send only one updated screen?

Yes. Use Send Screens or Select Screens, keep the relevant screens selected, and send a new export. Paste its new Copy Request into the same AI chat. Read the screen review guide.

Does MCP use transcription minutes?

No. Minutes are used when converting speech to text. Connecting, sending screenshots, and reading an export do not use transcription minutes.

Can the AI edit my Flow Capture project?

This connector is read-only. It can inspect the screens and comments you send. It cannot record your phone, change your library, or make purchases. An assistant may help edit code in its own workspace when you ask it to.

How do I remove access?

Open Settings → Integrations → Codex & Claude on iPhone, then disconnect the computer from its menu. Shared Access lets you remove shared copies. Already downloaded files cannot be recalled.
