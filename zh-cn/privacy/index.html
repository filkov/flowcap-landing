隐私政策

Flow Capture 如何处理您的项目、可选云功能、共享导出和帐户数据。

用于可选云功能的数据可选的产品分析和入门答案保留和删除权限这个网站隐私要求

此页面为译文。请参阅英文原文。

Flow Capture 是本地优先。项目、屏幕截图、屏幕录音和原始语音评论都会保留在用户的 iPhone 上，除非用户故意导出或发送它们。

用于可选云功能的数据

  • 帐户数据：存储姓名、电子邮件地址、私人帐户标识符、购买权利和连接集成元数据，以提供身份验证、购买、转录许可和集成。
  • 语音处理：当用户请求转录或评论润色时，选定的音频或评论文本以及链接的屏幕标题和识别的界面文本将被安全地发送到 Flow Capture 的处理提供商。请求完成后，临时云音频将被删除。原始音频和生成的文本保留在本地项目中。
  • Figma转账：只有当用户选择直接Figma转账时，才会上传流量包。为了将插件与正确的 Flow Capture 帐户配对，插件会将登录的 Figma 用户 ID 和显示名称发送到 Flow Capture。不透明的插件会话令牌存储在 Figma 客户端存储中。待处理包裹的有效期最长为 7 天。 Flow Capture 不会上传离线 ZIP 导出。
  • MCP AI转账：用户确认Send to AI后才上传包。它可能包括订购的屏幕截图、评论、提示和可用的原始音频。只有通过批准的配对代码连接的计算机才能获取帐户的显式共享导出。副本将在 7 天后过期，并且可以在 Settings → Codex & Claude → Shared Access 中提前删除。远程连接在 iPhone 上使用具有一次性批准的 OAuth。 AI服务拥有独立的、可撤销的访问和刷新凭证； Flow Capture 在其服务器上存储凭证哈希和加密的提供者凭证。您的 iPhone 会话不会与 AI 服务共享。连接在使用期间更新，并在 90 天不活动后过期。断开连接会阻止进一步读取，但不会删除 AI 服务已下载的文件。一旦用户要求 Claude 或 Codex 读取导出，则该客户自己的数据处理条款适用。 Flow Capture不会自动启动AI对话。
  • 购买：Apple 提供签名交易信息，以便 Flow Capture 可以解锁购买的功能和转录分钟。

远程连接器请求通过 Cloudflare 进行路由。身份验证、连接记录和显式共享导出存储托管在 Supabase 上。这些提供商处理交付集成所需的连接和请求数据；共享内容不可公开访问。

Flow Capture 不会出售个人数据、将其用于广告或跨应用程序和网站跟踪用户。服务提供商仅用于提供用户请求的功能，并且需要保护他们处理的数据。

可选的产品分析和入门答案

在您选择加入之前，共享将处于关闭状态。如果您选择 Share Answers & Usage，Flow Capture 会将您选择的调查选项、应用程序版本以及基本事件（例如应用程序会话、项目创建、打开 Flow Map 以及准备导出）发送到我们的 Supabase 后端。随机安装标识符对这些记录进行分组；它与您的云帐户分开，并且不是广告标识符。我们不会发送姓名、电子邮件、项目标题、屏幕截图、录音、评论文本、键入的搜索查询或其他用于分析的应用程序内容。托管提供商可以处理标准连接信息以操作和保护服务。

您可以在 Settings → Privacy & Data 中关闭共享。这将清除排队的事件并请求删除此安装的已发送分析。如果处于离线状态，则在线重新打开应用程序时会重试删除。分析记录和调查答案将在 90 天后过期。重新安装应用程序会创建新的安装，我们无法从您的电子邮件中识别以前的安装；其记录自动过期。禁用分析不会影响应用程序功能或订阅。我们使用这些记录来改进 Flow Capture，而不是用于广告、跨应用跟踪或 AI 培训。

保留和删除

临时转录音频在处理后将从云存储中删除。直接 Figma 传输包在 7 天后停止可用，并由 Flow Capture 的保留清理删除。撤销 Figma 集成会立即使其插件会话失效；当 Flow Capture 云帐户存在时，非活动连接元数据（包括 Figma 用户 ID 和显示名称）将保留。

用户可以永久删除其Flow Capture云帐户以及Settings › Account › Delete Account中关联的云数据。删除帐户不会删除本地项目和录音。删除 Flow Capture 帐户并不会取消 Apple 订阅；订阅可以在 App Store 帐户设置中进行管理。

帐户删除后，Flow Capture 可能会在必要时保留最小签名的 Apple 交易标识符，而无需活动的个人资料链接，以防止同一购买多次记入贷方、解决退款问题以及履行交易或防欺诈义务。

权限

仅当用户启用 Voice Commentary 或录制语音评论时，才请求 Microphone 访问。该应用程序继续支持本地捕获和组织，无需云帐户。 Figma 插件仅针对可选的直接传输配对请求 currentuser 权限；离线导入不使用Flow Capture的后端。

这个网站

该网站托管在 GitHub Pages 上，并使用 Google Fonts 提供的字体。这些提供商接收标准连接信息，例如您的 IP 地址和浏览器请求详细信息，以提供网站和字体。我们不在本网站上使用广告跟踪器或分析脚本。

隐私要求

使用上面的路径可以在应用程序内删除帐户。对于隐私请求，请联系 support@flowcap.me。请参阅支持以获取当前帮助和帐户指南。
