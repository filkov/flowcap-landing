01

连接 Claude

从目录开始，然后在聊天中启用 Flow Capture。

  1. 在您的计算机上，打开 Claude 连接器目录中的 Flow Capture。您也可以通过Customize→Connectors找到它。
  2. 选择连接到 Claude。
  3. 保持 Flow Capture 页面打开并在您的 iPhone 上批准其代码，如下所述。
  4. 返回 Claude 并在要使用它的聊天中启用 Flow Capture。
02

在您的 iPhone 上批准

一次性代码将 Claude 链接到您的 Flow Capture 帐户。

  1. 使用浏览器代码

    您的 AI 应用程序会打开一个 Flow Capture 页面，其中显示类似 ABCD-EFGH 的代码。保持该页面打开。

  2. 批准 Flow Capture

    打开Settings → Integrations → Codex & Claude → Add a Computer。如果出现提示，请登录，输入代码，检查请求应用程序的名称，然后确认。

  3. 返回您的 AI 应用

    浏览器完成连接。在 Claude 中，为要使用它的聊天启用 Flow Capture。 Claude 目前可直接连接。

代码是一次性的，最多可在 10 分钟内过期。如果代码过期，请在同一 AI 应用程序中重新启动 Connect。您永远不需要 Supabase 帐户、API 密钥或服务器安装。

03

发送流程以供审核

您选择屏幕。单独连接没有任何共享。

  1. 发送相关屏幕

    打开流程 → Share → Export for Codex or Claude → Send to AI。对于较小的切换，请使用 Select Screens 并仅导出您的选择。

  2. 开始审核

    发送后，点击 Copy Request 并将其粘贴到已连接的 Claude 聊天中。添加您想要查看或更改的内容。即使多个版本具有相同的名称，该请求也会标识准确的导出。

  3. 查找以前的导出

    询问：“显示我共享的 Flow Capture 导出并打开 [项目名称] 的最新导出。”只能找到可用的共享副本，而无法找到 iPhone 上未发送的项目。

在发送之前转录重要的语音评论。原始视频保留在 iPhone 上。每次导出都是一个快照：再次发送更新的屏幕以共享更改。每次云导出最多 200 个屏幕和 50 MB。 共享副本将在 7 天后过期。

想要分享 ZIP？
  1. 将选定的屏幕和注释导出为 AI 审阅 ZIP。
  2. Share 它带有一个接受文件的人工智能应用程序。如果无法打开 ZIP，请先解压缩包。
  3. 附上 START_HERE.txt 和相关屏幕，然后描述您要审核的内容。

要求和可用性

没有连接器下载或本地服务器。您需要在 iPhone 上使用 Flow Capture 并访问 Claude。直接云端交付需要Flow Capture Pro；您的 AI 应用程序的计划和使用限制单独适用。 iPhone 应用程序即将推出。

问题与帮助

连接、共享和访问。

我需要支付服务器费用吗？

不需要。Flow Capture 为您运行连接器。直接云发送需要Flow Capture Pro。您的 Claude 帐户自身的使用限制单独适用。

我的连接会过期吗？

连接在使用时会自动更新。 90 天未使用后，在您的 AI 应用程序中再次连接并在 iPhone 上批准新代码。 Shared 导出副本具有单独的 7 天生命周期。

我发送了一条流，但我的 AI 聊天中没有显示任何内容

Send to AI 可以导出；它不会发布消息。发送后点击 Copy Request，将其粘贴到已连接的 AI 聊天中，并请求审核。答案就出现在那次聊天中。

Flow Capture已连接，但Claude未使用

在 Claude 的连接器菜单中为当前聊天启用 Flow Capture。然后从 iPhone 应用程序发送您的屏幕并将 Copy Request 粘贴到该聊天中。单独连接不会共享项目或开始审核。

我的项目不见了

确保计算机连接到用于发送导出的同一个 Flow Capture 帐户。如果副本过期或被删除，请再次发送所需的屏幕。粘贴最新的 Copy Request 以选择准确的导出。

我可以只发送一张更新后的屏幕吗？

是的。使用 Send Screens 或 Select Screens，保持选择相关屏幕，然后发送新的导出。将新的 Copy Request 粘贴到同一个 AI 聊天中。 阅读屏幕查看指南。

MCP 使用转录分钟吗？

否。将语音转换为文本时使用分钟。连接、发送屏幕截图和读取导出内容不使用转录分钟数。

AI 可以编辑我的 Flow Capture 项目吗？

该连接器是只读的。它可以检查您发送的屏幕和评论。它无法录制您的电话、更改您的图书馆或进行购买。当您要求时，助手可以帮助在自己的工作区中编辑代码。

如何删除访问权限？

在 iPhone 上打开 Settings → Integrations → Codex & Claude，然后断开计算机与其菜单的连接。 Shared Access 允许您删除共享副本。已经下载的文件无法调用。
