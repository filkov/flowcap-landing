Конфиденциальность

Как Flow Capture обрабатывает проекты, данные аккаунта, облачные функции и отправленные материалы.

Это перевод. Читать оригинал на английском.

Flow Capture хранит данные прежде всего на устройстве. Проекты, скриншоты, записи экрана и исходные голосовые комментарии остаются на iPhone, пока пользователь сам не экспортирует или не отправит их.

Данные для дополнительных облачных функций

  • Данные аккаунта: имя, электронная почта, внутренний идентификатор аккаунта, сведения о доступе к покупкам и метаданные подключённых интеграций хранятся для входа в аккаунт, обработки покупок, учёта лимитов расшифровки и работы интеграций.
  • Обработка голоса: когда пользователь запрашивает расшифровку или улучшение комментариев, выбранное аудио либо текст комментария вместе с названиями связанных экранов и распознанным текстом интерфейса безопасно передаётся поставщикам услуг обработки Flow Capture. Временное аудио удаляется из облака после выполнения запроса. Исходное аудио и полученный текст остаются в локальном проекте.
  • Передача в Figma: материалы сценария загружаются только по запросу пользователя на прямую передачу. Для подключения к нужному аккаунту Flow Capture плагин отправляет идентификатор и отображаемое имя пользователя, вошедшего в Figma. Непрозрачный токен сеанса плагина хранится в клиентском хранилище Figma. Подготовленные материалы доступны до семи дней. ZIP-архивы для офлайн-экспорта Flow Capture не загружает на сервер.
  • Передача в ИИ через MCP: материалы загружаются только после подтверждения Send to AI. В них могут входить скриншоты по порядку, комментарии, запрос и доступное исходное аудио. Получать явно отправленные материалы аккаунта могут только компьютеры, подключённые с подтверждением кода. Копии доступны семь дней; удалить их раньше можно в Settings → Codex & Claude → Shared Access. Удалённое подключение использует OAuth с однократным подтверждением на iPhone. ИИ-сервис хранит отдельные отзываемые учётные данные для доступа и обновления; Flow Capture хранит их хэши и зашифрованные учётные данные поставщика на сервере. Сеанс iPhone не передаётся ИИ-сервису. Подключения продлеваются при использовании и истекают после 90 дней бездействия. Отключение закрывает дальнейший доступ, но не удаляет уже скачанные ИИ-сервисом файлы. Когда пользователь просит Claude или Codex прочитать экспорт, действуют условия обработки данных этого клиента. Flow Capture не начинает разговор с ИИ автоматически.
  • Покупки: Apple передаёт подписанные сведения о транзакциях, чтобы Flow Capture мог предоставить оплаченные функции и минуты расшифровки.

Запросы удалённого коннектора проходят через Cloudflare. На Supabase размещаются сервис входа, записи о подключениях и хранилище материалов, которыми пользователь явно поделился. Эти поставщики обрабатывают данные подключения и запросов, необходимые для работы интеграции. Отправленные материалы не находятся в открытом доступе.

Flow Capture не продает личные данные, не использует их для рекламы и не отслеживает пользователей в приложениях и на веб-сайтах. Поставщики услуг используются только для предоставления функций, запрошенных пользователем, и обязаны защищать данные, которые они обрабатывают.

Необязательная аналитика и ответы на вводные вопросы

Отправка аналитики отключена до вашего согласия. Если включить Share Answers & Usage, Flow Capture отправит в Supabase выбранные ответы на вводные вопросы, версию приложения и основные события: сеансы, создание проекта, открытие Flow Map и подготовку экспорта. Записи объединяются случайным идентификатором установки, который не связан с облачным аккаунтом и не является рекламным идентификатором. В аналитику не передаются имена, адреса электронной почты, названия проектов, скриншоты, записи, тексты комментариев, введённые поисковые запросы и другое содержимое приложений. Хостинг-провайдеры могут обрабатывать стандартные данные подключения для работы и защиты сервиса.

Отправку аналитики можно отключить в Settings → Privacy & Data. Это очищает очередь событий и запрашивает удаление ранее отправленной аналитики для этой установки. Если устройство офлайн, запрос повторяется при следующем открытии приложения с интернетом. Аналитика и ответы на вводные вопросы хранятся не более 90 дней. Переустановка создаёт новый идентификатор установки; определить прежнюю установку по электронной почте нельзя, а её записи удалятся по истечении срока хранения. Отключение аналитики не влияет на функции и подписки. Эти данные используются для улучшения Flow Capture, а не для рекламы, отслеживания между приложениями или обучения ИИ.

Хранение и удаление

Временное аудио для расшифровки удаляется из облака после обработки. Материалы прямой передачи в Figma становятся недоступны через семь дней и удаляются при плановой очистке Flow Capture. Отключение интеграции Figma сразу прекращает действие сеансов плагина. Метаданные неактивного подключения, включая идентификатор и отображаемое имя пользователя Figma, сохраняются, пока существует облачный аккаунт Flow Capture.

Пользователи могут навсегда удалить свою облачную учётную запись Flow Capture и связанные с ней облачные данные в Settings › Account › Delete Account. Локальные проекты и записи не удаляются при удалении учётной записи. Удаление учётной записи Flow Capture не отменяет подписку Apple; подписками можно управлять в настройках учётной записи App Store.

После удаления аккаунта Flow Capture может сохранять минимально необходимые подписанные идентификаторы транзакций Apple без действующей связи с профилем. Это необходимо для предотвращения повторного зачисления одной покупки, обработки возвратов и выполнения обязательств по транзакциям и борьбе с мошенничеством.

Разрешения

Доступ к микрофону запрашивается только при включении голосовых комментариев или записи голосовой заметки. Локальная запись и организация материалов доступны без облачного аккаунта. Плагин Figma запрашивает разрешение currentuser только для необязательного подключения прямой передачи; офлайн-импорт не использует сервер Flow Capture.

Вопросы о конфиденциальности

Удалить аккаунт можно в приложении по указанному выше пути. По вопросам конфиденциальности пишите на support@flowcap.me. Инструкции по работе с аккаунтом доступны в разделе поддержки.
