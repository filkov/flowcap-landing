¿Qué es Flow Capture?

Flow Capture convierte el flujo de usuarios de una aplicación de iPhone en pantallas ordenadas y comentarios vinculados a pantallas, para que pueda revisar el flujo y preparar una transferencia útil.

¿Qué puedo grabar o importar?

Registre el flujo de usuarios de una aplicación de iPhone o importe una grabación existente o un conjunto de capturas de pantalla. iOS o la aplicación de origen pueden impedir la captura de contenido protegido.

¿Puedo añadir comentarios de voz?

Sí. Puede narrar durante una grabación y agregar comentarios de texto a las pantallas guardadas. Las nuevas notas de voz y la transcripción en la nube dependen de su plan y de la asignación restante. Revise la ubicación de los comentarios y transcriba audio importante antes de una transferencia de IA. La grabación de pantalla en sí no utiliza minutos de transcripción. Lea la guía de voz.

¿Mis grabaciones salen del dispositivo?

Las grabaciones originales y los proyectos guardados permanecen en tu iPhone. La selección de pantalla se ejecuta localmente. Si solicita transcripción de voz, pulido de comentarios, entrega directa de Figma o uso compartido de MCP, esos servicios opcionales envían el audio, el texto o los datos de exportación relevantes para esa acción. Las exportaciones sin conexión permanecen locales hasta que las compartes.

¿Puedo enviar mis pantallas a Claude?

Sí. Conecte Flow Capture a Claude para enviar los materiales directamente. Por ahora, Claude es la única conexión directa compatible. También puede compartir un ZIP para análisis con IA sin conectar una app. Tras Send to AI, copie la solicitud con Copy Request y péguela en el chat de Claude. Cada envío crea una copia independiente y no actualiza la anterior. Cómo enviar los materiales.

¿Qué puedo enviar a Figma?

El plugin importa capturas como capas de imagen ordenadas y agrupadas por flujo. No reconstruye la interfaz como componentes editables. Se está preparando para su lanzamiento público y aún no está disponible en Figma Community.

¿Ya puedo descargar Flow Capture?

La app para iPhone y el plugin de Figma se están preparando para su lanzamiento público. Flow Capture llegará pronto a la App Store.
