01

Claudeに接続

まずディレクトリから始めて、チャットで Flow Capture を有効にします。

  1. コンピュータで、Claude コネクタ ディレクトリの Flow Capture を開きます。 Customize → Connectors でも見つけることができます。
  2. 「Claude に接続」を選択します。
  3. Flow Capture ページを開いたままにし、以下の説明に従って iPhone でコードを承認します。
  4. Claude に戻り、使用したいチャットで Flow Capture を有効にします。
02

iPhone で承認する

ワンタイム コードは、Claude を Flow Capture アカウントにリンクします。

  1. ブラウザコードを使用する

    AI アプリは、ABCD-EFGH のようなコードを示す Flow Capture ページを開きます。そのページを開いたままにしておきます。

  2. Flow Captureで承認

    Settings → Integrations → Codex & Claude → Add a Computer を開きます。求められたらサインインし、コードを入力し、要求元のアプリの名前を確認して確認します。

  3. AI アプリに戻る

    ブラウザが接続を完了します。 Claude で、使用するチャットに対して Flow Capture を有効にします。現在、Claude では直接接続が可能です。

コードは 1 回限りの使用で、最大 10 分で期限切れになります。コードの有効期限が切れた場合は、同じ AI アプリで Connect を再度開始します。 Supabase アカウント、API キー、サーバーのインストールは必要ありません。

03

レビューのためにフローを送信する

画面を選択するのはあなたです。接続するだけでは何も共有されません。

  1. 関連する画面を送信する

    フロー → Share → Export for Codex or Claude → Send to AI を開きます。ハンドオフを小さくするには、Select Screens を使用し、選択内容のみをエクスポートします。

  2. レビューを開始する

    送信後、「Copy Request」をタップして、接続されている Claude チャットに貼り付けます。確認または変更したいものを追加します。複数のバージョンが同じ名前を持つ場合でも、リクエストにより正確なエクスポートが識別されます。

  3. 以前のエクスポートを検索する

    「共有した Flow Capture エクスポートを表示して、[プロジェクト名] の最新のものを開いてください。」 iPhone 上の未送信のプロジェクトではなく、利用可能な共有コピーのみが検索されます。

重要な音声コメントを送信する前に文字に起こしてください。元のビデオはiPhoneに残ります。各エクスポートはスナップショットです。更新された画面を再度送信して、変更を共有します。最大 200 画面、クラウド エクスポートごとに 50 MB。 Shared コピーは 7 日後に期限切れになります。

ZIP を共有したいですか?
  1. 選択した画面とコメントを AI レビュー ZIP としてエクスポートします。
  2. Share ファイルを受け入れる AI アプリを使用します。 ZIP を開けない場合は、まずパッケージを解凍してください。
  3. START_HERE.txt と関連する画面を添付し、確認したい内容を説明します。

要件と可用性

コネクタのダウンロードやローカル サーバーはありません。 iPhone に Flow Capture が必要で、Claude にアクセスします。直接クラウド配信には Flow Capture Pro が必要です。 AI アプリのプランと使用制限は個別に適用されます。 iPhone アプリも近日公開予定です。

質問とヘルプ

接続、共有、アクセス。

サーバーの料金を支払う必要がありますか?

いいえ、Flow Capture がコネクタを実行します。クラウドへの直接送信には Flow Capture Pro が必要です。 Claude アカウント独自の使用制限は別途適用されます。

接続は期限切れになりますか?

使用中に接続は自動的に更新されます。 90 日間使用しなかった場合は、AI アプリで再度接続し、iPhone で新しいコードを承認します。 Shared エクスポート コピーには、個別の 7 日間の有効期間があります。

フローを送信しましたが、AI チャットに何も表示されませんでした

Send to AI によりエクスポートが可能になります。メッセージは投稿されません。送信後「Copy Request」をタップし、接続中のAIチャットに貼り付けてレビューを依頼してください。答えはそのチャットの中に表示されます。

Flow Capture は接続されていますが、Claude は使用しません

Claude のコネクタ メニューで現在のチャットに対して Flow Capture を有効にします。次に、iPhone アプリから画面を送信し、そのチャットに Copy Request を貼り付けます。接続するだけでは、プロジェクトを共有したり、レビューを開始したりすることはできません。

私のプロジェクトが見つかりません

コンピューターが、エクスポートの送信に使用したのと同じ Flow Capture アカウントに接続されていることを確認してください。コピーの有効期限が切れたか削除された場合は、必要な画面を再度送信します。最新の Copy Request を貼り付けて、正確なエクスポートを選択します。

更新された画面を 1 つだけ送信できますか?

はい。 Send Screens または Select Screens を使用し、関連する画面を選択したままにして、新しいエクスポートを送信します。新しい Copy Request を同じ AI チャットに貼り付けます。 画面レビュー ガイドをお読みください。

MCP は文字起こし議事録を使用しますか?

いいえ、議事録は音声をテキストに変換するときに使用されます。接続、スクリーンショットの送信、エクスポートの読み取りには、文字起こしの議事録は使用されません。

AI は私の Flow Capture プロジェクトを編集できますか?

このコネクタは読み取り専用です。送信した画面やコメントを検査できます。電話を録音したり、ライブラリを変更したり、購入したりすることはできません。アシスタントは、ユーザーのリクエストに応じて、独自のワークスペースでコードの編集を手伝ってくれる場合があります。

アクセスを削除するにはどうすればよいですか?

iPhone で Settings → Integrations → Codex & Claude を開き、メニューからコンピュータを切断します。 Shared Access を使用すると、共有コピーを削除できます。すでにダウンロードしたファイルを呼び出すことはできません。
