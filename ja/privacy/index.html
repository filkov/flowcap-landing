Flow Capture はローカルファーストです。プロジェクト、スクリーンショット、画面録画、および元の音声コメントは、ユーザーが意図的にエクスポートまたは送信しない限り、ユーザーの iPhone に残ります。

オプションのクラウド機能に使用されるデータ

  • アカウント データ: 名前、電子メール アドレス、プライベート アカウント ID、購入資格、接続統合メタデータは、認証、購入、文字起こし許可、統合を提供するために保存されます。
  • 音声処理: ユーザーが文字起こしやコメントの修正をリクエストすると、選択された音声、またはコメント テキストが、リンクされた画面タイトルおよび認識されたインターフェース テキストとともに Flow Capture の処理プロバイダーに安全に送信されます。一時的なクラウドオーディオは、リクエストが完了すると削除されます。元のオーディオと結果のテキストはローカル プロジェクトに残ります。
  • Figma 転送: フロー パッケージは、ユーザーが直接 Figma 転送を選択した場合にのみアップロードされます。プラグインを正しい Flow Capture アカウントとペアにするために、プラグインはサインインしている Figma ユーザー ID と表示名を Flow Capture に送信します。不透明なプラグイン セッション トークンは、Figma クライアント ストレージに保存されます。保留中のパッケージは最大 7 日間利用可能です。オフライン ZIP エクスポートは、Flow Capture によってアップロードされません。
  • MCP を介した AI 転送: パッケージは、ユーザーが Send to AI を確認した後にのみアップロードされます。これには、注文されたスクリーンショット、コメント、プロンプト、および利用可能なオリジナルの音声が含まれる場合があります。承認されたペアリング コードによって接続されているコンピューターのみが、アカウントの明示的に共有されたエクスポートを取得できます。コピーは 7 日後に期限切れになり、Settings → Codex & Claude → Shared Access で以前に削除できます。リモート接続では OAuth を使用し、iPhone で 1 回限りの承認を行います。 AI サービスは、取り消し可能なアクセスおよび更新資格情報を個別に保持します。 Flow Capture は、認証情報ハッシュと暗号化されたプロバイダー認証情報をサーバーに保存します。 iPhone セッションは AI サービスと共有されません。接続は使用中に更新され、非アクティブ状態が 90 日間続くと期限切れになります。切断するとそれ以上の読み取りはできなくなりますが、AI サービスによって既にダウンロードされたファイルは消去されません。ユーザーが Claude または Codex にエクスポートの読み取りを依頼すると、そのクライアント独自のデータ処理条件が適用されます。 Flow Capture は AI 会話を自動的に開始しません。
  • 購入: Apple は、Flow Capture が購入した機能と議事録のロックを解除できるように、署名済みの取引情報を提供します。

リモート コネクタの要求は Cloudflare 経由でルーティングされます。認証、接続レコード、明示的に共有されたエクスポート ストレージは Supabase でホストされます。これらのプロバイダーは接続を処理し、統合を提供するために必要なデータを要求します。共有コンテンツは一般公開されていません。

Flow Capture は、個人データを販売したり、広告に使用したり、アプリや Web サイト全体でユーザーを追跡したりすることはありません。サービス プロバイダーは、ユーザーが要求した機能を提供するためにのみ使用され、処理するデータを保護する必要があります。

オプションの製品分析とオンボーディングの回答

オプトインするまで共有はオフです。Share Answers & Usage を選択した場合、Flow Capture は、選択したアンケート オプション、アプリのバージョン、アプリ セッション、プロジェクトの作成、Flow Map のオープン、Supabase バックエンドへのエクスポートの準備などの基本イベントを送信します。ランダムなインストール識別子により、これらのレコードがグループ化されます。これはクラウド アカウントとは別のものであり、広告識別子ではありません。名前、電子メール、プロジェクト タイトル、スクリーンショット、録音、コメント テキスト、入力された検索クエリ、またはその他のアプリ コンテンツを分析のために送信することはありません。ホスティングプロバイダーは、サービスを運用および保護するために標準の接続情報を処理する場合があります。

Settings → Privacy & Data で共有をオフにできます。これにより、キューに入れられたイベントがクリアされ、このインストールの送信された分析の削除が要求されます。オフラインの場合、アプリをオンラインで再度開いたときに削除が再試行されます。分析記録とアンケート回答は 90 日後に期限切れになります。アプリを再インストールすると新しいインストールが作成され、メールから以前のインストールを特定することはできません。その記録は自動的に期限切れになります。分析を無効にしても、アプリの機能やサブスクリプションには影響しません。これらの記録は、広告、アプリ間追跡、AI トレーニングではなく、Flow Capture を改善するために使用されます。

保存と削除

一時的な文字起こし音声は、処理後にクラウド ストレージから削除されます。 Figma の直接転送パッケージは 7 日後に利用できなくなり、Flow Capture の保持クリーンアップによって削除されます。 Figma 統合を取り消すと、そのプラグイン セッションがただちに無効になります。 Flow Capture クラウド アカウントが存在する間、Figma ユーザー ID と表示名を含む非アクティブな接続メタデータは残ります。

ユーザーは、Flow Capture クラウド アカウントと、Settings › Account › Delete Account 内の関連するクラウド データを完全に削除できます。ローカルのプロジェクトと録音は、アカウントを削除しても削除されません。 Flow Capture アカウントを削除しても、Apple サブスクリプションはキャンセルされません。サブスクリプションは、App Store アカウント設定で管理できます。

アカウント削除後、Flow Capture は、同じ購入が複数回クレジットされることを防ぎ、返金を解決し、取引または詐欺防止の義務を果たすために、必要に応じてアクティブなプロファイル リンクなしで最小限の署名付き Apple 取引識別子を保持することがあります。

権限

Microphone アクセスは、ユーザーが Voice Commentary を有効にするか、音声コメントを録音する場合にのみ要求されます。このアプリは、クラウド アカウントなしでのローカル キャプチャと整理を引き続きサポートします。 Figma プラグインは、オプションの直接転送ペアリングに対してのみ currentuser 権限を要求します。オフライン インポートでは Flow Capture のバックエンドは使用されません。

このウェブサイト

この Web サイトは GitHub Pages でホストされており、Google Fonts によって提供されるフォントを使用しています。これらのプロバイダーは、Web サイトとフォントを配信するために、IP アドレスやブラウザー要求の詳細などの標準接続情報を受け取ります。このウェブサイトでは広告トラッカーや分析スクリプトは使用しません。

プライバシーのリクエスト

アカウントの削除は、上記のパスを使用してアプリ内で行うことができます。プライバシーに関するリクエストについては、support@flowcap.me までお問い合わせください。現在のヘルプとアカウントのガイダンスについては、サポートをご覧ください。
