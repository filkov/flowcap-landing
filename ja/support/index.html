録音とコメント

  • iPhone アプリを録画して画面を確認する
  • 音声コメントを追加し、トランスクリプトを確認する
  • スクリーンショットとコメントを Claude に送信する

コンピュータを接続する

MCP セットアップに従って Claude にリモート接続し、iPhone で承認してフローを送信します。セットアップ ページには、不足しているツール、期限切れのコード、1 つの画面の送信、レビューの開始に関するヘルプが含まれています。ローカルコネクタのインストールは必要ありません。 Claude の場合、コネクタ ディレクトリの Flow Capture を開き、[Claude に接続] を選択します。

購入と購読

Flow Capture でSettings → Account → Manage Subscriptionを開き、サブスクリプションを管理します。 iPhone のSettings → 自分の名前 → サブスクリプションでも管理できます。 App Store の請求に関する問題や払い戻しリクエストについては、Apple の購入サポートをご利用ください。

アカウントを削除するかストレージを解放する

Settings → Account → Delete Account を使用して、Flow Capture クラウド アカウントと関連するクラウド データを削除します。ローカルプロジェクトはiPhone上に残ります。アカウントを削除しても Apple サブスクリプションはキャンセルされません。

Settings → Storageを使用して、プロジェクトのサイズを確認し、ビデオまたはプロジェクト全体を削除します。ビデオのみを削除すると、スクリーンショットとコメントは保持されますが、そのビデオからそれ以上のフレームを復元できなくなります。

問題レポートを準備する

Flow Capture で、Settings → Report a Problem を開いてレポートを準備します。予想したこと、何が起こったのか、そしてそれを再現する手順を含めてください。レポートを support@flowcap.me に送信します。パスワード、ペアリング コード、またはプライベートな録音は含めないでください。

プライバシーと規約

データの処理と保持についてはプライバシー ポリシーを、アプリのライセンスと購入のガイダンスについては利用規約をお読みください。
