# Flow Capture — landing

Static landing page for [flowcap.me](https://flowcap.me). Plain HTML + CSS + a little JS, no build step.

Layout follows the Lumior concept by arounda (inset hero with bottom-left headline, overlapping sheet, statement + bento, steps with a curved progress line, side-text carousel, logo strip, finale with a footer card and a giant wordmark), adapted to a dark theme with the Flow Capture app palette. Typeface: Urbanist (free stand-in for Gilroy). 3D objects are the Flow Capture glass icons with the background keyed out.

Hosted on GitHub Pages from the `main` branch. Local preview: `node .claude/serve.mjs` → http://127.0.0.1:8765/
