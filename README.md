# Flow Capture — landing

Static landing page for [flowcap.me](https://flowcap.me). Plain HTML + CSS + a few lines of JS, no build step.

Structure and rhythm follow lookaway.com (pill nav, centered hero with app icon, feature blocks with a glowing icon, chips rows, "Designed for" block, giant wordmark in the footer). Palette, mark, icons and content are Flow Capture's own.

Hosted on GitHub Pages from the `main` branch. Local preview: `node .claude/serve.mjs` → http://127.0.0.1:8765/
